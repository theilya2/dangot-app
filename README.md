# Dangot Notifications

אפליקציית אנדרואיד שמקבלת התראות קריאה בזמן אמת ממאגר Firebase של יומן הטכנאים,
ומקפיצה התראת מסך-מלא שמצלצלת עד לחיצת "אישור".

## בנייה אוטומטית (APK)
כל דחיפה ל-main מפעילה GitHub Actions שבונה APK.
להורדה: לשונית **Actions** → הריצה האחרונה → **Artifacts** → `dangot-notifications-apk`.

## התקנה
1. העבר את ה-APK לטלפון והתקן (אפשר "מקורות לא ידועים").
2. פתח את האפליקציה, בחר את שם הטכנאי, לחץ "הירשם והפעל".
3. אשר הרשאות התראות, ובטל אופטימיזציית סוללה לאפליקציה.

מאגר הנתונים מוגדר בקובץ `app/src/main/java/il/co/dangot/alerts/Const.kt`.
